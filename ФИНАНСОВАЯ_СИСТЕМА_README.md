# 🎬 СИСТЕМА АВТОМАТИЧЕСКОЙ ГЕНЕРАЦИИ ФОТО И ВИДЕО

## 📌 ОПИСАНИЕ ПРОЕКТА

Создана полная **100% БЕСПЛАТНАЯ** система для автоматизированной генерации фото и видео с применением AI агента.

### Три компонента системы:

1. **D:/ПРОЕКТ КИНО** - Система автоматизации контента (Фото + Видео)
   - Groq API интеграция (генерация промптов) - БЕСПЛАТНО
   - Stable Diffusion (генерация фото) - БЕСПЛАТНО (Hugging Face)
   - FFmpeg (создание видео) - БЕСПЛАТНО (open source)
   - GitHub Actions автоматизация - БЕСПЛАТНО
   - Google Sheets для хранения данных - БЕСПЛАТНО
   - Python скрипты для полной автоматизации

2. **F:/НИША КОНТЕНТА** - Обучающие материалы для AI агента
   - 6 файлов документации (2,500+ строк)
   - 3 уровня обучения
   - Адаптация для создания видео контента
   - Интеграция со всеми бесплатными API

3. **F:/МЕДИА БИБЛИОТЕКА** - Сгенерированный контент
   - Сгенерированные фото (PNG, JPG)
   - Созданные видео (MP4)
   - Промпты и метаданные
   - Статистика генераций

## 🎯 БЕСПЛАТНЫЕ ИНСТРУМЕНТЫ

### 1. Groq API
- **Что:** Генерация текстовых промптов для фото
- **Цена:** БЕСПЛАТНО (до 10k запросов в день)
- **Где:** https://console.groq.com
- **Модель:** mixtral-8x7b (очень быстрая)

### 2. Hugging Face Stable Diffusion
- **Что:** Генерация фотографий из текста
- **Цена:** БЕСПЛАТНО (до 100 фото в день)
- **Где:** https://huggingface.co/api/inference
- **Модель:** stabilityai/stable-diffusion-3

### 3. FFmpeg
- **Что:** Создание видео из фото и звука
- **Цена:** БЕСПЛАТНО (open source)
- **Установка:** `apt-get install ffmpeg` или `brew install ffmpeg`

### 4. gTTS (Google Text to Speech)
- **Что:** Добавление голоса в видео
- **Цена:** БЕСПЛАТНО
- **Установка:** `pip install gtts`

### 5. GitHub Actions
- **Что:** Автоматизация (запуск каждый день)
- **Цена:** БЕСПЛАТНО (до 2000 минут в месяц)

### 6. Google Sheets API
- **Что:** Хранение данных и обратная связь
- **Цена:** БЕСПЛАТНО
- **Установка:** Service Account

## 🎯 СЛЕДУЮЩИЕ ШАГИ

1. **Получить бесплатные ключи**
   - Groq: https://console.groq.com (регистрация, копировать ключ)
   - Google: https://console.cloud.google.com (создать Service Account)

2. **Установить зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настроить GitHub Actions**
   - Добавить Secrets в GitHub (GROQ_API_KEY, GOOGLE_SHEETS_KEY)
   - Включить Actions в репо

4. **Запустить первый раз**
   - GitHub Actions → Run workflow
   - Или локально: `python scripts/generate_prompts.py`

5. **Мониторить результаты**
   - Google Sheets каждый день
   - F:/МЕДИА БИБЛИОТЕКА (фото и видео)
   - Дать обратную связь
   - Система улучшается
