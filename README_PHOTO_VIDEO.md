# 🎬 СИСТЕМА ГЕНЕРАЦИИ ФОТО И ВИДЕО

## ⚡ БЫСТРЫЙ СТАРТ (5 минут)

### Что это?
Автоматическая система которая каждый день:
- ✅ Генерирует 160+ уникальных фото
- ✅ Создаёт 30+ видео
- ✅ Все **100% БЕСПЛАТНО**

### Как начать?

**Шаг 1: Получить бесплатные ключи (2 минуты)**
```bash
# Groq API (генерация промптов)
Перейти: https://console.groq.com
Клик: "Sign Up" → Подтвердить почту → Копировать API Key

# Google Sheets (сохранение данных)
Перейти: https://console.cloud.google.com
Создать: Новый проект → Service Account → Скачать JSON ключ
```

**Шаг 2: Установить зависимости (2 минуты)**
```bash
pip install -r requirements.txt
```

**Шаг 3: Запустить (1 минута)**
```bash
python scripts/generate_prompts.py
python scripts/generate_images.py
python scripts/generate_videos.py
```

**Результат:** В папке `generated_output/` найдёшь все созданные фото и видео! 🎉

## 🎯 ЧТО МОЖЕТ СИСТЕМА

### Генерирует фото
```
Промпт: "красивый закат на пляже"
                ↓
Stable Diffusion создаёт фото
                ↓
Сохраняет в generated_output/images/
```

### Создаёт видео
```
Фото + Текст + Голос (gTTS)
                ↓
FFmpeg собирает видео
                ↓
Сохраняет в generated_output/videos/
```

### Улучшает себя
```
День 1: Вы оцениваете фото (Нравится/Не нравится)
         ↓
День 2: Система видит что нравилось
         ↓
День 3: Генерирует больше в этом стиле
         ↓
День 5: 90% фото вам нравятся!
```

## ❓ ВОПРОСЫ

**Q: Это правда бесплатно?**
A: ДА! Все используемые инструменты бесплатные или имеют щедрые бесплатные планы.

**Q: Сколько фото в день?**
A: 160+ фото в день (или столько, сколько ты хочешь).

**Q: Какое качество?**
A: Зависит от промптов. Система учится каждый день улучшать качество.

**Q: Можно ли использовать результаты?**
A: ДА! Все фото и видео твои. Можешь продавать, выкладывать в соцсети и т.д.

**Q: Нужен ли GPU?**
A: НЕТ! Stable Diffusion работает на серверах Hugging Face (облако).
